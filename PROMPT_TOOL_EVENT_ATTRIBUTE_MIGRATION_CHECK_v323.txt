实现说明
- prompt-tool.html 删除全部静态 onclick，并用稳定 ID / data-* 属性保存目标参数。
- js/prompt-tool-page.js 新增一次性静态事件绑定，调用现有最终生效的全局函数，不改函数内部业务逻辑。
- js/prompt-tool-ui.js 的 setActiveNav 改为读取 data-section-target；不再依赖已删除的 onclick 文本。
- prompt-tool-ui.js 与 prompt-tool-page.js 缓存查询参数更新为 ?v=323。
- prompt-tool-core.js 保持逐字节不变。
