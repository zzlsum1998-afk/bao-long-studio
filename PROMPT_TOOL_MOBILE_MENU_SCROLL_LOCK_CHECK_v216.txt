BaoLong Lab v216 - Prompt Tool mobile menu scroll lock fix

Base package:
- baolong-contact-methods-formal-v215-full-noimage.zip

Goal:
- Fix Prompt Tool mobile menu issue where page/background content can still scroll while the menu panel is open.

Changed files:
- prompt-tool.html

Changes made:
1. Enhanced Prompt Tool mobile menu script:
   - Opening mobile menu now locks the page behind it.
   - Closing menu restores the original scroll position.
   - Clicking outside the menu closes it.
   - Pressing Escape closes it.
   - Clicking a menu link closes it.
   - Resizing to desktop width closes it.
   - aria-expanded is updated on the menu button.

2. Added mobile menu panel scroll containment:
   - -webkit-overflow-scrolling: touch;
   - overscroll-behavior: contain;
   - body.mobile-menu-open { overflow: hidden; }
